# WiFi Security Checklist for Small Teams

Adapted from the full guide: [ops-notes/wifi-security-checklist](https://hive80-lab.github.io/ops-notes/wifi-security-checklist)

## Checklist

- [ ] Find the router admin address and actually log in — if the default admin password still works, that is finding #1
- [ ] Screenshot the status page: firmware version, SSIDs in use, connected device count (this is your baseline)
- [ ] Write the date and who did it on a note kept with the IT gear
- [ ] Change the admin password to a unique value in the password manager — admin and WiFi passwords are two different credentials, always
- [ ] Turn off remote administration and UPnP unless something genuinely needs them; log exceptions with an owner and a review date
- [ ] Disable WPS push-button pairing (known attacks; exists only to save typing a password once)
- [ ] WPA3 or WPA2-AES only; no WEP, no open network bridged to the office LAN
- [ ] Separate guest SSID, isolated from office devices
- [ ] Update firmware, then calendar a 15-minute quarterly router check
- [ ] Re-review connected device count: is every device still explainable?
- [ ] Replace or lock down the ISP combo box in sensitive setups (disable its WiFi at minimum)
- [ ] Store the WiFi password in the password manager with a rotation plan and staff comms note
